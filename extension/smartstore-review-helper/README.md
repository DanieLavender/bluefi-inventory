# 블루파이 리뷰 답글 도우미 (크롬 확장)

스마트스토어 판매자센터 리뷰 화면에 **AI 답글 초안** 버튼을 추가해주는 크롬 확장 프로그램입니다.
AI 호출은 블루파이 서버가 담당하므로, 이 확장에는 API 키가 들어있지 않습니다.
직원 토큰만 있으면 사용할 수 있습니다.

> ⚠ 이 도구는 **초안만** 만들어줍니다. 답글 등록 버튼은 항상 사람이 직접 눌러야 합니다
> (자동 등록 기능은 일부러 넣지 않았습니다 — 네이버 약관 준수).

---

## 1. 설치 방법 (개발자 모드 로드)

1. 이 폴더(`smartstore-review-helper`)를 통째로 PC에 복사해 둡니다.
   (압축파일로 받았다면 **압축을 먼저 풀어주세요.**)
2. 크롬 주소창에 `chrome://extensions` 를 입력하고 이동합니다.
3. 오른쪽 위의 **개발자 모드** 스위치를 켭니다.
4. 왼쪽 위의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
5. 1번에서 복사해 둔 `smartstore-review-helper` 폴더를 선택합니다.
6. 목록에 **"블루파이 리뷰 답글 도우미"** 가 나타나면 설치 완료입니다.

> 💡 폴더를 삭제하거나 이동하면 확장이 꺼집니다. 폴더는 그대로 두세요.

## 2. 최초 설정 (딱 한 번)

1. 크롬 오른쪽 위 퍼즐 조각(🧩) 아이콘 → **블루파이 리뷰 답글 도우미** 클릭
   (자주 쓴다면 핀 📌 을 눌러 고정해 두세요.)
2. 설정 창이 열리면:
   - **서버 주소**: 기본값 그대로 두면 됩니다
     (`http://cosguardian.lavenderfriends.co.kr:3001`)
   - **직원 토큰**: 관리자에게 받은 토큰을 붙여넣습니다.
3. **[저장]** 을 누른 뒤 **[연결 테스트]** 를 눌러 "연결 성공"이 나오는지 확인합니다.
   - 실패 메시지가 나오면 그 화면을 캡처해서 관리자에게 보내주세요.

### 답글 규칙 수정 (선택)

같은 설정 창 아래쪽의 **스토어 답글 규칙** 칸에서 답글 말투/규칙을 고칠 수 있습니다.
규칙은 서버에 저장되므로 **한 명이 수정하면 모든 직원에게 바로 적용**됩니다.

## 3. 사용 방법

1. 스마트스토어 **판매자센터 → 리뷰 관리** 화면으로 이동합니다.
2. 답글을 달 리뷰의 답글 입력칸을 엽니다.
3. 입력칸 근처에 생긴 **✨ AI 답글 초안** 버튼을 클릭합니다.
   - 이때 화면에 보이는 **같은 상품의 다른 리뷰와 기존 등록 답글**(최대 5건, 개인정보
     필터 동일 적용)도 함께 참고 자료로 서버에 전송되어, 답글 톤이 일관되게 유지됩니다.
4. 잠시 후 답글 후보 3개가 나타납니다. 마음에 드는 후보를 **클릭하면 입력칸에 채워집니다.**
   - 마음에 안 들면 **[↻ 다시 생성]** 을 누르세요.
   - 채워진 글은 자유롭게 고쳐도 됩니다.
5. 내용을 확인한 뒤 **네이버의 답글 등록 버튼을 직접** 눌러 등록합니다.

### ⚠ 저평점 리뷰

별점이 낮은 리뷰는 패널 위에 빨간 경고 띠가 표시됩니다.
이 경우 초안을 **그대로 쓰지 말고 반드시 내용을 확인·수정** 후 등록해주세요.

### "AI가 읽은 내용 보기"

버튼 옆의 이 링크를 누르면, AI에게 실제로 전송되는 내용(리뷰 본문·상품명·별점 등)을
확인할 수 있습니다. **리뷰 내용이 이상하게 잘려 보이면 이 화면을 캡처해서 관리자에게
보내주세요** — 화면 구조 변경에 맞춰 조정해드립니다.

## 4. 자주 묻는 문제

| 증상 | 해결 방법 |
|------|-----------|
| 버튼이 안 보여요 | 페이지를 새로고침(F5)하고, 답글 입력칸을 먼저 열어보세요. |
| "확장이 업데이트되었습니다. F5로 새로고침해주세요" | 말 그대로 페이지를 F5로 새로고침하면 됩니다. |
| "직원 토큰이 설정되지 않았습니다" | 2번(최초 설정)을 다시 진행해주세요. |
| 연결 테스트 실패 | 사내망/서버 상태 문제일 수 있습니다. 오류 메시지를 캡처해 관리자에게 전달해주세요. |
| 후보 클릭해도 입력칸이 안 채워져요 | 입력칸을 한 번 클릭한 뒤 다시 후보를 눌러보세요. 그래도 안 되면 관리자에게 알려주세요. |

## 5. 개인정보 관련

- 리뷰에 포함된 **키/몸무게/체형 등 신체정보 줄은 서버로 전송하기 전에 자동 삭제**됩니다.
- 확장은 판매자센터 화면에 보이는 리뷰 내용만 읽으며, 별도 수집/저장을 하지 않습니다.
